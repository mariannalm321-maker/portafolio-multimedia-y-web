Cafetería Local Moderna

Diseño de sitio web acogedor y estilizado, 100% centrado en la experiencia del usuario. Desarrollado en WordPress con Elementor, cuenta con menú interactivo, sistema de reserva de espacios y módulo de e-commerce para pedidos en línea. Optimizado para móviles, con alojamiento gratuito y carga rápida. Una fusión entre calidez local y estética moderna.

Tienda de Ropa

E-commerce dinámico y visual codificado desde cero en Visual Studio Code con HTML5, CSS3 y JavaScript. Cuenta con catálogo visual de productos, categorías organizadas, filtros por colección y diseño totalmente adaptable (responsive). Integra carrito de compras con checkout directo a WhatsApp para cerrar ventas al instante, animaciones suaves y optimización de velocidad para una experiencia de compra fluida y moderna.
